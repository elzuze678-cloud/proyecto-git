# Guía de Contribución

¡Gracias por tu interés en contribuir a este proyecto! Las contribuciones son lo que hace que la comunidad de código abierto sea un lugar tan increíble para aprender, inspirar y crear.

## Cómo Contribuir

### 1. Fork el Repositorio
Haz un fork del repositorio a tu cuenta de GitHub.

### 2. Clona tu Fork
```bash
git clone https://github.com/tu-usuario/proyecto-git.git
cd proyecto-git
```

### 3. Crea una Rama
```bash
git checkout -b feature/tu-feature
```

### 4. Realiza tus Cambios
- Mantén los cambios enfocados y claros
- Sigue las convenciones de código existentes
- Comenta tu código cuando sea necesario

### 5. Commit y Push
```bash
git add .
git commit -m "Descripción clara de los cambios"
git push origin feature/tu-feature
```

### 6. Abre un Pull Request
- Describe claramente qué cambios realizaste
- Menciona cualquier issue relacionado
- Espera la revisión y feedback

## Estándares de Código

- Usa 2 espacios para indentación
- Mantén líneas menores a 100 caracteres
- Comenta código complejo
- Sigue las convenciones de nombres existentes

## Reportar Bugs

Si encuentras un bug:
1. Verifica que no esté reportado
2. Abre un issue describiendo:
   - Pasos para reproducir
   - Comportamiento esperado
   - Comportamiento actual
   - Tu entorno (SO, navegador, versión)

## Sugerencias y Features

Las sugerencias son bienvenidas. Abre un issue con:
- Descripción clara de la sugerencia
- Caso de uso
- Beneficios potenciales

---

¡Gracias por contribuir!
